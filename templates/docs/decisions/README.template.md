## 2. 流程

1. **业务 / 产品** 在 [`../SPEC.md`](../SPEC.md) §8 找到对应 Q-NN 的卡，写决议、签名、改状态。
2. **工程** 同步本表的状态、决议人、日期。
3. **重审** 时不得直接覆盖旧决议；状态改为 🔁，在卡片中追加新一轮决议并保留旧版作为评论。
4. **里程碑阻断**：所有状态仍为 ⏳ 的卡，对应里程碑不允许启动。

## 3. 与 ADR 的关系

- 业务决议（Q-NN）回答「系统应该做什么」；
- ADR 回答「工程上如何做」；
- 一个业务决议可能触发一篇新 ADR；
- 反向：ADR 不能独自改写业务事实，遇到要改业务行为时**必须**回到 SPEC 决议卡走流程。
