## 4. 加 / 改 / 删依赖的流程

1. 先查白名单 / 黑名单；命中黑名单直接驳回。
2. 改 `package.json`（或等价），lockfile 同步提交。
3. 起一篇 ADR（workflow §1 场景 5）。
4. `install --frozen-lockfile` 确认无漂移。
